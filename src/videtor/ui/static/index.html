New project

A project turns one shoot and one brief into a Premiere timeline.

1Read the footage→ 2Brief & plan→ 3Cut→ 4Review→ 5Import in Premiere
How this works
  1. Plug in the drive with the footage. Nothing is copied or moved.
  2. Choose the footage folder; the name fills in from it.
  3. Create project. Videtor reads every take (faces, speech, what each shot shows) and sorts the shots by type: about ten minutes for a day's shoot. The project opens straight away, so you can paste the brief while it reads. A notification says when it is done.
  4. Keep the drive connected until the cut: the first cut reads in full the takes it needs.
The shoot's folder on its drive; cards and subfolders inside are fine.
Names the project folder and the Premiere XML.

Library

Sort a shoot into folders by shot type, and pull out every interview bite, without making a cut.

How this works
  1. Choose a footage folder and Add; add more when the shoot spans drives or cards.
  2. Sort the footage. Every clip is read and sorted into wide, close-up, talking-head, interview-bite and b-roll folders (links: the footage stays where it is). Clips with someone speaking are transcribed so their sentences become bites, laid out as a Premiere sequence.
  3. Check the sheets below. Wrong type? Change it in the clip's list (it moves the link), or move links between the folders in Finder.
  4. Learn from my sorting: from then on, every library and every new project sorts the way you do.
